# lessoneasyenglish — تعلّم الإنجليزية بسهولة

صفحة ويب لتعلّم أهم **1000 كلمة إنجليزية شائعة** مع النطق الصحيح والمعنى بالعربي.

## طريقة العمل
- يدرس المتعلّم **5 كلمات فقط** في كل درس؛ لكل كلمة زر 🔊 للنطق العادي وزر للنطق البطيء.
- لا يُفتح الدرس التالي إلا بعد اجتياز اختبارين:
  1. **الاختبار الأول:** يظهر المعنى بالعربي ويكتب المتعلّم الكلمة بالإنجليزية.
  2. **الاختبار الثاني** (يُفتح بعد اجتياز الأول): تظهر الكلمة بالإنجليزية ويكتب معناها بالعربي.
- يجب أن تكون الإجابات الخمس صحيحة لاجتياز كل اختبار.
- يُحفظ التقدّم تلقائياً في المتصفح، وتظهر الكلمات المُتقنة في تبويب «كلماتي».

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو انشر المستودع عبر GitHub Pages.

## الملفات
- `index.html` — هيكل الصفحة
- `styles.css` — التصميم (يدعم الجوال والوضع الليلي)
- `app.js` — منطق الدروس والاختبارات والنطق
- `words.js` — قائمة الكلمات الألف ومعانيها
